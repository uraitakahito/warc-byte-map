# warc-byte-map

A viewer that shows which bytes of a WARC (Web ARChive) file each term of the WARC 1.1 specification (record, header, block, payload, …) refers to. Open it at <https://uraitakahito.github.io/warc-byte-map/>.

## Documentation

Everything — how to read the viewer, the link format, and development — lives on the docs site:

- **English** — <https://uraitakahito.github.io/warc-byte-map/docs/>
- **日本語** — <https://uraitakahito.github.io/warc-byte-map/docs/ja/>

## Related Projects

- [warc-specifications](https://github.com/uraitakahito/warc-specifications) — the fork of the IIPC (International Internet Preservation Consortium) specifications with the annotated WARC 1.1 that the viewer links to, and that links back to the viewer.
